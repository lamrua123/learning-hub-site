    Bài 040 — Comprehension có kiểm soát

    🎯 Hôm nay học gì?

    Bạn đã biết tạo list bằng vòng lặp:

    numbers = [1, 2, 3, 4]
doubled_numbers = []

for number in numbers:
    doubled_numbers.append(number * 2)

    Python có một cách viết gọn cho những phép tạo collection đơn giản:

    numbers = [1, 2, 3, 4]
doubled_numbers = [number * 2 for number in numbers]

    Cách viết đó gọi là comprehension.

    Trong bài này, ta sẽ học:

    • comprehension là gì;
    • cách dịch comprehension về loop thường;
    • list comprehension để biến đổi và lọc dữ liệu;
    • conditional expression A if condition else B;
    • sự khác nhau giữa filter và chọn giá trị;
    • kết hợp comprehension với slicing, unpacking, enumerate() và zip();
    • dictionary comprehension;
    • duplicate key trong dictionary comprehension;
    • set comprehension;
    • vì sao cú pháp ngoặc tròn không tạo tuple comprehension;
    • nested comprehension ở mức vừa đủ;
    • side effect và shared reference;
    • khi nào comprehension giúp code rõ hơn;
    • khi nào loop thường là lựa chọn tốt hơn;
    • xây mini-project dùng comprehension cho transformation và loop cho validation.

    Mục tiêu không phải là:

    Biến mọi vòng lặp thành một dòng.

    Mục tiêu là:

    Dùng comprehension cho một phép biến đổi rõ ràng, có kiểm soát; giữ loop thường khi nó diễn đạt ý định tốt hơn.

    🧒 Hiểu cực đơn giản

    Hãy tưởng tượng một băng chuyền số:

    1, 2, 3, 4

    Bạn muốn tạo list mới bằng cách nhân đôi từng số:

    2, 4, 6, 8

    Loop thường mô tả từng bước:

    Tạo list rỗng.
Lấy từng số.
Nhân đôi số đó.
Append kết quả.

    Comprehension mô tả collection muốn xây:

    doubled_numbers = [number * 2 for number in numbers]

    Đọc là:

    Với mỗi number trong numbers,
hãy tạo number * 2,
rồi thu các kết quả vào một list mới.

    Nếu chỉ muốn số chẵn:

    even_numbers = [number for number in numbers if number % 2 == 0]

    Đọc là:

    Với mỗi number trong numbers,
nếu number là số chẵn,
hãy đưa number vào list mới.

    Comprehension tốt giống một câu ngắn, rõ.

    Comprehension xấu giống một câu quá dài có nhiều điều kiện, nhiều hành động và nhiều tầng lồng nhau.

    🧠 1. Comprehension là gì?

    Comprehension là cú pháp tạo một collection mới từ dữ liệu có thể duyệt.

    Ba loại chính trong bài:

    list comprehension
dictionary comprehension
set comprehension

    Ví dụ:

    numbers = [1, 2, 3, 4]

squares = [number * number for number in numbers]
square_by_number = {number: number * number for number in numbers}
parities = {number % 2 for number in numbers}

print(squares)
print(square_by_number)
print(len(parities))

    Ý nghĩa:

    squares          -> list các bình phương
square_by_number -> dictionary số: bình phương
parities         -> set các số dư khác nhau

    🧠 2. Luôn biết cách mở rộng thành loop

    Comprehension:

    numbers = [1, 2, 3, 4]
squares = [number * number for number in numbers]

    Loop tương đương:

    numbers = [1, 2, 3, 4]
squares = []

for number in numbers:
    square = number * number
    squares.append(square)

    Hai phiên bản tạo cùng dữ liệu.

    Comprehension không phải phép thuật.

    Nó chỉ tập trung vào collection kết quả.

    Khi không hiểu một comprehension, hãy mở rộng nó thành loop thường.

    Nếu loop đã có nhiều nhánh và nhiều hành động, ép nó thành comprehension thường không làm logic dễ hiểu hơn.

    🧩 3. List comprehension cơ bản

    Cú pháp:

    [expression for item in source]

    Trong đó:

    source     -> dữ liệu đầu vào
item       -> biến nhận từng phần tử
expression -> giá trị đưa vào list mới

    Ví dụ:

    prices = [100, 250, 80]
prices_with_fee = [price + 10 for price in prices]

print(prices_with_fee)

    Kết quả:

    [110, 260, 90]

    Ánh xạ từng phần:

    source     = prices
item       = price
expression = price + 10

    🔍 4. Thứ tự đọc

    Xét:

    names = [" mai ", "AN", " lan"]
clean_names = [name.strip().title() for name in names]

    Hãy đọc theo thứ tự:

    1. for name in names
2. name.strip().title()
3. thu kết quả vào list

    Loop tương đương:

    names = [" mai ", "AN", " lan"]
clean_names = []

for name in names:
    clean_name = name.strip().title()
    clean_names.append(clean_name)

    🧠 5. Mapping — mỗi input tạo một output

    Biến đổi từng phần tử (mapping) có nghĩa:

    mỗi input element -> một output element

    Ví dụ số:

    damages = [3, 5, 8]
critical_damages = [damage * 2 for damage in damages]

print(critical_damages)

    Kết quả:

    [6, 10, 16]

    Ví dụ records:

    players = [
    {"name": "Mai", "score": 980},
    {"name": "An", "score": 870}
]

player_names = [player["name"] for player in players]

print(player_names)

    Kết quả:

    ['Mai', 'An']

    🧠 6. List comprehension có filter

    Cú pháp:

    [expression for item in source if condition]

    Ví dụ chỉ giữ số chẵn:

    numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)

    Kết quả:

    [2, 4, 6]

    Loop tương đương:

    numbers = [1, 2, 3, 4, 5, 6]
even_numbers = []

for number in numbers:
    if number % 2 == 0:
        even_numbers.append(number)

    Điều kiện ở cuối quyết định phần tử có được đưa vào list mới hay không.

    🧩 7. Vừa lọc vừa biến đổi

    scores = [35, 80, 60, 95, 40]
passing_labels = ["PASS:" + str(score) for score in scores if score >= 50]

print(passing_labels)

    Kết quả:

    ['PASS:80', 'PASS:60', 'PASS:95']

    Loop tương đương:

    scores = [35, 80, 60, 95, 40]
passing_labels = []

for score in scores:
    if score >= 50:
        label = "PASS:" + str(score)
        passing_labels.append(label)

    Input trượt condition không tạo output.

    🧠 8. Filter không sửa source

    scores = [35, 80, 60, 95, 40]
passing_scores = [score for score in scores if score >= 50]

print(scores)
print(passing_scores)

    Kết quả:

    [35, 80, 60, 95, 40]
[80, 60, 95]

    Comprehension tạo list container mới.

    Nó không tự xóa phần tử khỏi source.

    Shared objects bên trong sẽ được phân tích ở phần sau.

    🔮 9. Đoán kết quả — mapping và filtering

    numbers = [1, 2, 3, 4, 5]

result_a = [number + 10 for number in numbers]
result_b = [number for number in numbers if number > 3]
result_c = [number * 2 for number in numbers if number % 2 == 1]

print(result_a)
print(result_b)
print(result_c)

    Hãy viết chính xác ba lists rồi mở rộng từng comprehension thành loop.

    🧠 10. Conditional expression

    Python có biểu thức điều kiện (conditional expression):

    value_if_true if condition else value_if_false

    Ví dụ:

    score = 75
label = "PASS" if score >= 50 else "FAIL"

print(label)

    Kết quả:

    PASS

    Nó phù hợp khi chỉ chọn ngắn gọn giữa hai giá trị.

    Nếu mỗi nhánh cần nhiều bước, dùng if/else statement thường.

    🧠 11. Conditional expression trong comprehension

    Ta muốn giữ mọi vị trí nhưng đổi score thành label:

    scores = [35, 80, 60, 40]
labels = ["PASS" if score >= 50 else "FAIL" for score in scores]

print(labels)

    Kết quả:

    ['FAIL', 'PASS', 'PASS', 'FAIL']

    Loop tương đương:

    scores = [35, 80, 60, 40]
labels = []

for score in scores:
    if score >= 50:
        label = "PASS"
    else:
        label = "FAIL"

    labels.append(label)

    🧠 12. Hai vị trí if có ý nghĩa khác nhau

    if ở cuối — lọc

    scores = [35, 80, 60, 40]
passing_scores = [score for score in scores if score >= 50]

print(passing_scores)

    Kết quả:

    [80, 60]

    if ... else ... ở đầu — chọn giá trị

    scores = [35, 80, 60, 40]
labels = ["PASS" if score >= 50 else "FAIL" for score in scores]

print(labels)

    Kết quả:

    ['FAIL', 'PASS', 'PASS', 'FAIL']
    Mẫu Ý nghĩa Số output
    [x for x in data if condition] lọc có thể ít hơn input
    [A if condition else B for x in data] chọn giá trị bằng số input

    }

    categories = {
        item["category"]
        for item in items
    }

    summaries = [
        {
            "item_id": item["item_id"],
            "name": item["name"],
            "total_value": item["quantity"] * item["unit_price"]
        }
        for item in items
    ]

    return {
        "available_items": available_items,
        "low_stock_ids": low_stock_ids,
        "stock_labels": stock_labels,
        "value_by_id": value_by_id,
        "categories": categories,
        "summaries": summaries
    }
